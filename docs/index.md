### Project Summary

The Smart Gripper we are constructing is an end-effector that uses a five-node architecture. A central Master bus node (powered by a PIC18F57Q43) coordinates telemetry from four dedicated peripheral subsystems: grip actuation, tactile force sensing, infrared proximity detection, and a 3-axis accelerometer utilizing op-amps for real-time slip detection. By continuously polling sensor data and evaluating logic states across the UART network, the master controller dynamically adjusts motor actuation. This closed-loop feedback allows the system to autonomously adjust its grip strength, ensuring it can safely secure delicate items without crushing them and automatically recover if payload slippage is detected.
